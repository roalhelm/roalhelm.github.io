Hermes Control

Support & Help

Hermes Control is an iPhone and iPad app for Hermes Agent, the self-hosted AI agent on your Mac or server. The app connects directly to the Hermes dashboard on your own machine, with no cloud service in between.

What the app does

  • Chat with your agent, follow replies live and stop them
  • Approve tool calls that need confirmation
  • Search, pin, archive and delete chats
  • View profiles with model and skills and start new chats in them
  • View, pause, resume, run and create cron jobs
  • Connection status, Hermes version and connected messengers at a glance

Setup

  1. On the machine running Hermes Agent, set a session token (environment variable HERMES_DASHBOARD_SESSION_TOKEN).
  2. Start the dashboard reachable on your network, for example hermes dashboard --host 0.0.0.0 --port 9119.
  3. In the app, open Settings and add a gateway: the machine's IP address or host name and the token.
  4. Tap "Verbindung testen" (test connection), then save.

Outside your home network I recommend an encrypted HTTPS connection, for example through a VPN or Tailscale.

Common problems

  • No connection: Is the dashboard running and not bound to 127.0.0.1 only? Are the iPhone and the machine on the same network? Does the app have "Local Network" permission in iOS Settings?
  • Error 401 or 403: The token in the app does not match the token on the machine.
  • Chats load but no replies arrive: Check that Hermes Agent itself has a working model configured.

Privacy

  • The app collects no data, uses no tracking and needs no account.
  • All content travels only between your device and your own Hermes server.
  • The token is stored in the iOS keychain.

Details are in the privacy policy.
