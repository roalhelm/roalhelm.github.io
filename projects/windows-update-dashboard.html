Microsoft Update Dashboard

Alle kumulativen Windows-Updates auf einen Blick, gruppiert nach Produkt und Feature-Update-Version. Die Daten kommen bei jedem Build direkt von den offiziellen Update-History-Seiten auf Microsoft Support, mit Datum, KB-Nummer und OS-Build.

Dashboard öffnen GitHub ansehen

Was es zeigt

  • Windows 10 und Windows 11 – aktuell Windows 10 22H2 und Windows 11 23H2, 24H2, 25H2 und 26H2
  • Je Update – Veröffentlichungsdatum, KB-Nummer, OS-Build und Link zur Microsoft-Seite
  • Update-Typ – Security/Quality, Preview und Out-of-band getrennt filterbar
  • Suche und Filter – nach KB, Build oder Version sowie nach Produkt, Jahr und Monat
  • Hell und dunkel – Farbschema per Klick umschaltbar

So funktioniert es

Ein GitHub-Actions-Workflow läuft täglich, bei jedem Push und auf Knopfdruck. Er lädt die in config/sources.json hinterlegten Seiten von support.microsoft.com, liest Datum, KB und Build aus und erzeugt daraus data/updates.json. Danach wird die Seite auf GitHub Pages veröffentlicht. Der Browser fragt Microsoft also nicht selbst ab, sondern bekommt eine frische, statische Datei.

Fällt eine Quelle aus, steht das sichtbar im Dashboard. Fallen alle Quellen aus, wird nicht veröffentlicht, damit nie eine leere oder veraltete Übersicht live geht.

Daten und Sicherheit

  • Kein Microsoft Graph – keine Tenant-Rechte, keine App Registration, keine Secrets
  • Nur offizielle Quellen – Allowlist auf support.microsoft.com, nur HTTPS, Timeout und Größenlimit
  • Strenge CSP – die Seite lädt nur eigene Skripte und Daten
  • Minimale Workflow-Rechte – contents: read, pages: write, id-token: write

Grenzen

Microsoft veröffentlicht die Update-History als HTML, nicht als stabile JSON-API. Ändert sich das Markup, kann der Parser ausfallen; Tests decken das erwartete Format ab. Office und Teams nutzen andere Formate und sind noch nicht enthalten. Weitere Feature-Versionen kommen über einen Eintrag in config/sources.json dazu.
