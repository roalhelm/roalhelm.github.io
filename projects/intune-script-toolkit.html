WindowsAutopatchFix

Intelligente Erkennung und Reparatur von Windows Update-Fehlern als Intune Proactive Remediation. Fuehrt nur aus, was wirklich defekt ist – kein unnötiger Eingriff ins System.

⭐ 8 Stars v3.3 / v2.2 MIT License

Was es macht

Das Skript besteht aus zwei Teilen: detection.ps1 prueft, ob Windows Update Probleme vorliegen, und remediation.ps1 behebt sie gezielt. 15 unabhaengig konfigurierbare Reparaturschritte werden nur ausgefuehrt, wenn sie benoetigt werden.

Features

  • Smart Detection – DLL-Versionspruefung, BitLocker-Status, Service-Abhaengigkeiten, Fehlercode-Dictionary (20+ Codes)
  • 15 konfigurierbare Reparaturschritte – Registry-Cleanup, DLL-Reregistrierung, WSUS-Artefakte entfernen, Autopatch-Check u.v.m.
  • Service Retry Logic – 3 Versuche mit exponentiellem Backoff (500 ms → 1 s → 2 s)
  • Auto Log Rotation – 10 MB Limit, letzte 5 Logs behalten
  • Unterstuetzte Fehlercodes: 0x80070002, 0x80240034, 0x800F0922, 0xC1900200 und mehr

Deployment in Intune

Devices → Scripts and remediations → Proactive remediations → + Create
Detection: detection.ps1  |  Remediation: remediation.ps1
Run as: System  |  64-bit PowerShell: Yes  |  Schedule: Daily

Dateien

  • detection.ps1 (v2.2) – Diagnose mit BitLocker-Check, DLL-Validierung, Netzwerktests; Exit 0 = OK, Exit 1 = Reparatur nötig
  • remediation.ps1 (v3.3) – Intelligente Reparatur mit 15 konfigurierbaren Schritten
  • Test-WindowsUpdateFix.ps1 – Lokales Testskript vor dem Intune-Deployment

Anforderungen

Windows 10/11 · Microsoft Intune · PowerShell 5.1+ · System/Admin-Berechtigungen
