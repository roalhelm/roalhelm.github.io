Intune DeviceOS Report

PowerShell-Skript zum Abrufen detaillierter Windows-11-Geräteinformationen aus Microsoft Intune – inklusive OS-Version, Build-Nummer, KB-Update, Hersteller und Smart Recommendations.

v1.2 168 Builds GPL-3.0

Was es macht

Das Skript verbindet sich über die Microsoft Graph API mit Intune und erstellt einen detaillierten CSV-Report über alle verwalteten Geräte – inklusive Feature-Update-Version, Release-Datum, KB-Nummer und automatischen Handlungsempfehlungen.

Eingabemethoden

  • CSV-Datei – Liste von Computernamen aus Clients.csv
  • Manuelle Eingabe – Einzelne oder mehrere Geräte direkt eingeben
  • Azure AD-Gruppe – Alle Geräte einer Entra-ID-Gruppe abfragen

Report-Felder

  • OS-Version, Feature Update (22H2, 23H2, 24H2, 25H2), KB-Nummer, Update-Typ
  • Seriennummer, Hersteller, Modell, Primary User UPN
  • Freier Festplattenspeicher (GB), letzter Intune-Check-in
  • Intune Management Status, Entra ID Status, Tage seit letztem Check-in
  • Recommended Action – Automatische Empfehlung basierend auf Gerätestatus

Build-Datenbank

Enthalten sind 168 Windows-11-Builds von 2022 bis 2025: 78× 22H2, 60× 23H2, 26× 24H2, 4× 25H2.

Benötigt

PowerShell 7.0+ · Microsoft Graph PowerShell SDK · Berechtigungen: DeviceManagementManagedDevices.Read.All, Device.Read.All
