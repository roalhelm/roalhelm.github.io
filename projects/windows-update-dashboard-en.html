Microsoft Update Dashboard

All cumulative Windows updates at a glance, grouped by product and feature update version. The data is fetched on every build straight from the official update history pages on Microsoft Support, with date, KB number and OS build.

What it shows

  • Windows 10 and Windows 11 – currently Windows 10 22H2 and Windows 11 23H2, 24H2, 25H2 and 26H2
  • Per update – release date, KB number, OS build and a link to the Microsoft page
  • Update type – Security/Quality, Preview and Out-of-band can be filtered separately
  • Search and filter – by KB, build or version, and by product, year and month
  • Light and dark – switch the color scheme with one click

How it works

A GitHub Actions workflow runs daily, on every push and on demand. It loads the pages listed in config/sources.json from support.microsoft.com, reads date, KB and build, and generates data/updates.json. The site is then published to GitHub Pages. So the browser does not query Microsoft itself; it gets a fresh static file.

If a source fails, the dashboard shows it. If every source fails, nothing is published, so an empty or stale overview never goes live.

Data and security

  • No Microsoft Graph – no tenant permissions, no app registration, no secrets
  • Official sources only – allowlist for support.microsoft.com, HTTPS only, timeout and size limit
  • Strict CSP – the page only loads its own scripts and data
  • Minimal workflow permissions – contents: read, pages: write, id-token: write

Limitations

Microsoft publishes the update history as HTML, not as a stable JSON API. If the markup changes, the parser can break; tests cover the expected format. Office and Teams use other formats and are not included yet. More feature versions are added with one entry in config/sources.json.
